# 临时考试

教师入口：`/teacher/temporary-exams`。原期末考试入口也有链接。

1. 选择“使用本次 Python 入门试卷”，或导入符合示例格式的 JSON 文件。界面支持下载完整题库示例，并预览全部题目、答案和评分建议。
2. 设置场次名称、计划开始及统一结束时间，创建后点击“开启考试”。该按钮以点击时间为实际开始时间。
3. 复制 `/exam/{考试ID}` 链接发给考生。考生无需账号，填写学号、姓名，通过按钮进入全屏。身份首次登记后姓名不能随意更改。
4. 教师可刷新查看答卷、切屏次数及监考记录。考生交卷后可逐题人工评分和填写评语。
5. 按场次导出 XLSX 成绩、ZIP 试卷和答卷，也可导出单个考生答卷。ZIP 内的 HTML 可打印或另存为 PDF，另附结构化题库和原始评分记录 JSON。参考答案为教师专用，单独存放。

## 本次试卷结构

原始学生卷共15题、100分、60分钟，保留四大题分组及代码缩进。

| 题目 | 分值 | 评分 |
| --- | --- | --- |
| 1—5 单选 | 20 | 自动 |
| 6—9 代码阅读完整输出 | 20 | 自动 |
| 10 固定函数名填空 | 5 | 自动 |
| 11—13 代码补全和改错 | 15 | 人工 |
| 14—15 编程 | 40 | 人工 |

自动评分共45分，人工评分共55分。原文件无答案，参考答案和评分建议根据题意整理，可在开考前预览核对。代码补全允许多种等价写法，交给教师评阅，避免字符串判等误判正确代码。

## 保存和监考规则

- 输入停止700毫秒后保存，每5秒再同步一次；服务端串行版本校验避免旧请求覆盖新答案。
- 失焦、隐藏标签、退出全屏、离开页面及断网会锁定答题界面，清空身份输入框。续答必须重新填写原学号和姓名，并恢复全屏。
- 续答保留服务端答卷、原截止时间，并轮换写入凭证，另一标签或设备的旧凭证立即失效。学号、姓名属于身份核对，不具备账号密码的身份认证强度。
- 每位考生截止时间为“首次进入 + 题库时长”与“场次统一结束”中较早者。续答不会重新计时。服务端拒绝截止后的答案，到时和教师提前结束均按已保存内容交卷。
- 考生页倒计时会触发交卷；关闭页面的考生在下一次教师读取、导出或身份核对时按原截止时间结算，无需后台定时任务。
- 本标签页缓存未上传草稿。没有其他页面写入时可在续答恢复；有更新版本时以服务端为准。浏览器被强制关闭、突然断网时只能保证最后成功保存的数据，页面会提示保存失败。
- 浏览器全屏必须由用户点击触发；不支持全屏的浏览器不能开答。建议电脑端 Chrome / Edge，通过 HTTPS 访问。浏览器失焦检测用于监考记录，无法替代系统级锁定浏览器。
- 本模块沿用期末考试的禁止复制、粘贴和题干右键规则。代码在浏览器中编辑，由教师评分，不运行考生代码。
- 考生接口不返回标准答案、评分规则、实时分数、其他考生记录；教师数据按教师ID隔离。待评题目标为待评，最终分数仅在已交卷且全部人工题评分后导出。

## 题库文件

示例：`resources/temporary-exams/python-basics-60.json`。必须是 UTF-8 JSON，最大1MB，`version: 1`。

顶层字段：`title`、`durationMinutes`、`totalScore`、`instructions`、`sections`、`questions`，可选 `answerKeyNote`。每题必须有唯一 `id`、唯一 `number`、`sectionId`、`type`、`grading`、`score`、`content`。

题型支持 `SINGLE`、`MULTIPLE`、`JUDGE`、`OUTPUT`、`FILL`、`CODE`、`TEXT`。`CODE`、`TEXT` 必须 `MANUAL`；其余题型可按需指定自动或人工。自动题必须提供 `answers` 字符串数组，数组元素表示可接受的等价答案。多选的一组答案写为 `"A,C"`，全对得分。代码题可提供教师专用 `referenceAnswer`、`rubric`。题干代码使用 `code` 字段，换行和缩进保留。

自动文本题仅统一换行、去掉首尾空白和行尾空格，仍要求内部字符及换行一致；不执行程序、不使用AI判分。题库有总分校验、重复ID和题号校验、答案与选项匹配检查。

## 数据库和验证

新增三张独立表 `TemporaryExam`、`TemporaryExamAttempt`、`TemporaryExamEvent`，不依赖学生账号，不改变原期末考试评分逻辑。

在项目正常数据库升级流程中执行：

```sh
npx prisma db push
npx prisma generate
npm run build
```

另提供仅包含本模块新增表、索引和外键的 SQL：`prisma/temporary-exams.sql`，适用于未采用 Prisma schema 同步的部署流程，不要重复执行。上线时须先更新数据库，再重启新版应用。

本机验证：

```sh
npx tsc --noEmit --incremental false
npx tsx scripts/test-temporary-exams.ts
```

集成测试连接配置的数据库，创建专用临时教师和考试，验证后删除该测试教师及其考试，不触碰已有教师数据。
